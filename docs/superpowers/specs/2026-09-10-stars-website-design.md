# STARS Pizza & Döner – Website Design

## Ziel
Statische, mobile-first One-Page-Website für den Imbiss/die Pizzeria "STARS – Pizza & Döner" in Bad Berka. Schwarz-Gold-Design, komplette Speisekarte als strukturierte Daten (nicht als Bild), Call-to-Action für Anruf/Anfahrt. Deployment über GitHub Pages im Repo `JustinPriem/shawarma-stars.de`.

## Nicht-Ziele
- Kein Online-Bestellsystem, kein Warenkorb, keine Zahlungsabwicklung
- Keine aktuelle Rabattaktion (die im Flyer abgebildete 15%-Jubiläumsaktion war nur 08.–12.09.2025 gültig und wird nicht übernommen)
- Kein CMS/Backend, keine Datenbank
- Keine Stockfotos/KI-Bilder – rein typografisch/dekoratives Schwarz-Gold-Design mit Icon-Akzenten

## Design (Schwarz-Gold)
- **Farben:** Hintergrund tiefschwarz (#0b0b0c / #141414), Gold-Akzent (#d4af37 bis #f5d67a Verlauf), Text hell (#f5f0e6), dezente Gold-Trennlinien/Ornamente wie auf dem Flyer
- **Typografie:** Auffällige Headline-Schrift für Logo/Headings (z. B. Google Font "Cinzel" oder "Playfair Display"), gut lesbare Sans-Serif für Fließtext/Speisekarte (z. B. "Inter")
- **Layout:** Sticky-Header mit Logo + Nav + Telefon-Button; Hero mit Goldverlauf-Headline und zwei CTA-Buttons; Speisekarte in Kategorie-Tabs/Accordions, je Gericht Name/Beschreibung/Preis(e); Öffnungszeiten als zweispaltige Tabelle (Abholung/Lieferung); Kontakt-Sektion mit eingebetteter Google-Maps-Karte (iframe, keine API-Key-Pflicht) und Adresse/Telefonlinks; Footer mit Kurzinfo
- **Bilder:** keine Fotos – dekorative CSS-Ornamente (Sterne/Linien passend zum "STARS"-Branding), Icons/Emoji als Akzente
- **Responsiveness:** Mobile-first, Speisekarte scrollt/klappt sauber auf kleinen Screens, Nav wird zum Hamburger-Menü unter ~768px

## Technische Umsetzung
- `index.html`, `css/style.css`, `js/script.js` – keine Frameworks, keine Build-Tools
- Menüdaten direkt als semantisches HTML (Listen/Definitionslisten) im HTML eingebettet, nicht per JSON/JS generiert (einfacher zu pflegen, funktioniert ohne JS, gut für SEO)
- Kategorie-Filter/Tabs per kleinem Vanilla-JS (progressive enhancement – ohne JS sind einfach alle Kategorien untereinander sichtbar)
- `tel:`-Links für Telefonnummern, Google-Maps-Link für Route
- Keine externen Abhängigkeiten außer optional Google Fonts (CDN)

## Deployment
- Lokales Git-Repo verbunden mit `https://github.com/JustinPriem/shawarma-stars.de`
- Push auf `main`
- GitHub Pages Aktivierung (Branch `main`, Root) muss der Nutzer einmalig in den Repo-Settings bestätigen, falls nicht schon aktiv – ich weise am Ende darauf hin

## Testing/Verifikation
- Lokale Vorschau im Browser (Datei direkt öffnen bzw. lokalen Server) auf Darstellung, Responsiveness (Mobile/Desktop), Links (`tel:`, Maps, Anker-Navigation) prüfen
- Kein automatisierter Test nötig (statische Seite ohne Logik-Kern)
